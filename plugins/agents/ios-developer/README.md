# ios-developer

Native iOS development agent with Swift/SwiftUI, Core Data, UIKit, and networking.

## Installation

```bash
/plugin install ios-developer@aleksei-plugins
```

## Usage

```
"use ios-developer to implement this SwiftUI view"
"use ios-developer to set up Core Data models"
```

## Model

`opus` — architecture decisions, complex iOS features, security-critical code.

## Focus Areas

- SwiftUI declarative UI and Combine framework
- UIKit integration and custom components
- Core Data and CloudKit synchronization
- URLSession networking and JSON handling
- App lifecycle and background processing
- iOS Human Interface Guidelines compliance
