# android-developer

Native Android development agent with Kotlin, Jetpack Compose, and Material Design 3.

## Installation

```bash
/plugin install android-developer@aleksei-plugins
```

## Usage

```
"use android-developer to implement this Compose screen"
"use android-developer to set up Room database"
```

## Model

`opus` — architecture decisions, complex Android features, Jetpack integration.

## Focus Areas

- Jetpack Compose declarative UI
- Material Design 3 components and theming
- Kotlin Coroutines and Flow
- Room database and DataStore
- Retrofit/Ktor networking
- Hilt dependency injection
