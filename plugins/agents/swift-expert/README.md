# swift-expert

Expert Swift developer agent for Swift 5.9+, async/await, SwiftUI, and protocol-oriented programming.

## Installation

```bash
/plugin install swift-expert@aleksei-plugins
```

## Usage

```
"use swift-expert to optimize this async code"
"use swift-expert to review concurrency safety"
```

## Model

`opus` — deep Swift analysis, concurrency review, performance optimization.

## Focus Areas

- Modern Swift 5.9+ patterns
- Async/await and actor-based concurrency
- Protocol-oriented design
- SwiftUI mastery
- Memory management and ARC
- Server-side Swift with Vapor
