# flutter-expert

Cross-platform Flutter/Dart development agent with state management and platform integrations.

## Installation

```bash
/plugin install flutter-expert@aleksei-plugins
```

## Usage

```
"use flutter-expert to set up state management"
"use flutter-expert to implement platform channels"
```

## Model

`sonnet` — standard cross-platform development, UI implementation, testing.

## Focus Areas

- Widget composition and custom widgets
- State management (Provider, Riverpod, Bloc)
- Platform channels and native integration
- Responsive design and adaptive layouts
- Performance profiling and optimization
- Testing strategies (unit, widget, integration)
