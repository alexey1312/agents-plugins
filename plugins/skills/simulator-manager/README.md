# simulator-manager

Manage iOS simulators — list, create, boot, and configure for testing.

## Installation

```bash
/plugin install simulator-manager@aleksei-plugins
```

## Usage

Auto-invoked when user asks about simulators:

```
"list available simulators"
"boot iPhone 15 Pro simulator"
"take a simulator screenshot"
```

## Features

- List, boot, shutdown simulators
- Create and delete custom simulators
- Install and launch apps
- Screenshots and screen recording
- Status bar overrides for App Store screenshots
