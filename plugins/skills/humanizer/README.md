# Humanizer

Remove signs of AI-generated writing from text.

## Installation

```bash
/plugin install humanizer@aleksei-plugins
```

## Usage

```bash
/humanizer
```

## Features

- Detects 24 AI writing patterns across content, language, style, and communication
- Rewrites text to sound natural and human-written
- Based on Wikipedia's "Signs of AI writing" guide
- Preserves meaning while adding voice and personality
