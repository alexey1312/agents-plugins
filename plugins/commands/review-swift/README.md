# review-swift

Comprehensive Swift code review using swift-expert agent.

## Installation

```bash
/plugin install review-swift@aleksei-plugins
```

## Usage

```bash
/review-swift                    # Review staged changes
/review-swift path/to/file.swift # Review specific file
/review-swift --all              # Review all Swift files
```

## Review Checklist

- Swift 5.9+ best practices
- Concurrency safety (actors, Sendable)
- Performance and memory management
- SwiftLint compliance
- Test coverage
